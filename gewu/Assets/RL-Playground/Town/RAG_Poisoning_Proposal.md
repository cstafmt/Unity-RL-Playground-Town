# 对抗性记忆投毒：针对 RAG 具身视觉 Agent 的攻击与防御

> 一页研究计划 · 基于现有 Unity 小镇探索系统（i2t 视觉 + RAG 记忆 + 自主寻宝）

## 1. 问题与动机

现有具身 agent 通过"截图 → 视觉模型描述 → 写入 RAG 记忆 → 检索辅助决策"形成闭环。
这条闭环有一个尚未被系统研究的攻击面：**写入记忆的视觉观测本身可被对抗性污染**。
一旦一条虚假观测（如"FOUND: 黄色宝箱在 X 处"）进入长期记忆，它会被 RAG 反复检索、
经决策循环不断放大，造成持续而非一次性的行为偏差。

研究问题：
- **RQ1（攻击）** 对手能否通过在环境中布置物理诱饵，使其被 agent 写入 RAG 记忆，从而长期误导决策？污染如何随时间放大？
- **RQ2（防御）** 多观测一致性 + 可信度加权能否在不损失探索效率的前提下抑制污染？
- **RQ3（博弈）** 攻击强度与防御开销之间的权衡曲线是什么？

## 2. 威胁模型

- **攻击者能力**：可在场景中放置/移动有限数量的物理诱饵（复用现有 `HiderAgent` 的 decoy 机制）；
  **不能**直接读写 agent 内存、不能访问其 RAG 数据库、不能改提示词。攻击仅通过"被看见"间接发生。
- **攻击者知识**：黑盒。仅知道目标是某类宝物（颜色/形状先验），不知 agent 内部状态。
- **目标**：最大化（a）虚假宝物被采纳率、（b）真宝物被找到的延迟、（c）记忆中被污染条目的留存时长。
- **防御者**：即现有 agent，只能改记忆写入/检索与判定逻辑，不能改场景。

## 3. 攻击设计

| 层级 | 机制 | 来源 |
|---|---|---|
| L0 静态诱饵 | 随机布置，关键词与真宝物部分重合 | 现有 `HiderAgent` |
| L1 路径诱饵 | 放在 seeker 与真宝物之间，诱导走偏 | 现有 `GetDecoyPlacementPosition` |
| L2 记忆放大 | 诱饵被多次观测 → 在 RAG 中形成高权重虚假簇 | **新增**：利用 recencyWeight |
| L3 自适应投毒 | 依据 seeker 已探索区域（信念模型）动态布置，专攻检索盲区 | **新增**：替换现有随机决策 |

关键指标：**Poison Propagation Factor (PPF)** = 单次虚假观测在后续 K 步决策中被检索命中的次数。

## 4. 防御设计（收编现有 `TreasureIdentifier`）

1. **多观测一致性**：同一物体需 ≥N 次独立观测，方差过高则降权（已有雏形）。
2. **可信度计算（需补全）**：当前 `credibility` 为外部传入，应由观测距离、视角、VLM 置信度真实计算。
3. **跨视角几何核验**：同一"宝物"在不同视角下的估计位置须一致，否则判为诱饵。
4. **记忆检疫**：被判为 decoy 的观测从 RAG 中移除或标记负权重，阻断 L2 放大。

## 5. 评测矩阵

- **场景**：easy / medium / hard（遮挡与诱饵密度递增，复用 `ExperimentTracker.sceneName`）。
- **方法 A/B/C/D**（复用现有字段）：A 无防御；B 仅一致性；C 一致性+可信度；D 全防御+记忆检疫。
- **攻击层级**：L0–L3 各跑一遍，构成攻防矩阵。
- **每格 ≥10 trial**，报均值±方差与统计显著性（配对检验）。

核心指标（`ExperimentTracker` 已采集大部分）：
真宝物找到率/延迟、诱饵误采纳率（攻击成功率）、PPF、污染留存时长、
VLM 调用数与防御计算开销、路径长度。

## 6. 与现状的差距（必须补齐）

1. 接入**真实 VLM**，弃用 `ComputeFeatureMatch` 的字符串匹配（保留为 baseline）。
2. 真正实现 **L2/L3 攻击**与 **PPF 指标采集**。
3. **可信度**的真实计算公式。
4. **记忆检疫**写回 RAG 的逻辑。
5. 信念模型替换 `HiderAgent` 中的 `Random.value` 决策。

## 7. 目标 venue

- 保底：具身/安全 workshop（CVPR/NeurIPS/ICRA workshop）。
- 主攻：AAMAS / CoRL / ICRA（具身多智能体）或 安全侧 CCS/NDSS（RAG poisoning 线）。
- 卖点：首个把"RAG 记忆投毒"落到**物理具身视觉 agent**上的攻防研究。

## 8. 里程碑（建议 8 周）

第 1–2 周接真 VLM + 补可信度；第 3–4 周实现 L2/L3 攻击与 PPF；
第 5 周记忆检疫防御；第 6–7 周跑满攻防矩阵；第 8 周写作与消融。
